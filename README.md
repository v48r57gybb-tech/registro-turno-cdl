# Registro turno Centri Di Lavoro

Modulo mobile per FR01 e FR03. Operatori: Martino, Daniel, Manuel, Munir.

## Attivazione del sito
Nel repository aprire Settings > Pages. In Build and deployment scegliere Deploy from a branch, ramo main, cartella /(root), poi Save. Attendere che GitHub mostri il link e aprirlo in Safari o Chrome. Non usare l'anteprima dell'allegato HTML.

## Utilizzo
Compilare il modulo e premere OK — Genera riepilogo. Controllare i dati, poi scegliere WhatsApp — testo oppure salvare il documento HTML/TXT. Confermare manualmente l'invio e il destinatario. La condivisione del documento dipende dal dispositivo. Stampa / PDF apre la stampa del browser: controllare l'anteprima.

## Dati e limiti
Bozze locali separate per macchina, nessuna sincronizzazione tra dispositivi, autenticazione o archivio centrale. Il browser non è un archivio affidabile: salvare le copie importanti ed esportare backup. Nessun service worker: apertura offline non garantita. Nessuna libreria esterna o raccolta delle compilazioni su server. Il codice e i nomi nel modello sono pubblici. Non caricare registrazioni o backup nel repository. La condivisione scelta dall'utente passa dati ad altre app.

## Collaudo prima dell'uso
Inserire dati fittizi con codice PROVA-001. Passare da FR01 a FR03 e tornare per controllare le bozze separate. Generare il riepilogo, salvare HTML e riaprirlo: deve mostrare PROVA-001 senza campi modificabili. Provare WhatsApp con una chat di prova e verificare PDF e backup. Non ancora collaudato su dispositivo iPhone/iPad fisico.

Le attività di manutenzione sono promemoria: seguire sempre le procedure aziendali e di sicurezza.
